### 🇪🇸 ESPAÑOL: DESCRIPCIÓN & METODOLOGÍA

**Arqueólogo Creativo** es un framework de auditoría forense, deliberación dialéctica y asignación de recursos diseñado para profesionales creativos (guionistas, diseñadores narrativos, desarrolladores de software/videojuegos, ilustradores y creadores de contenido) que sufren parálisis por coste hundido o acumulación de proyectos inconclusos.

El sistema ejecuta un escaneo jerárquico de metadatos de solo lectura, reconstruye la trayectoria longitudinal, cuantifica el embudo de conversión de activos y somete cada proyecto a un tribunal de 6 agentes especializados con cálculo del **Índice de Eficiencia Económica (IE) corregido por factor de fricción** y **experimentos binarios de 48 horas**.

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 🏛️ EL TRIBUNAL AUDITOR DE 6 AGENTES (SISTEMA DE DELIBERACIÓN):                         │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. 💎 AGENTE 01 (IP Scout): Oportunidad de mercado, adaptabilidad y reencuadre.       │
│ 2. 🎨 AGENTE 02 (Art Critic): Calidad de oficio, voz autoral y originalidad.          │
│ 3. 🎯 AGENTE 03 (Buyer Persona / Investor): Disposición de pago real B2C vs B2B.       │
│ 4. 👹 AGENTE 04 (Red Team / Hater): Antítesis crítica, costes ocultos y saturación.   │
│ 5. 💰 AGENTE 05 (Financial CFO): Facturación histórica, tarifas y ratio de eficiencia.│
│ 6. 🧠 AGENTE 06 (Operational Psychologist): Síntesis operativa y roadmap atómico.      │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 📐 FÓRMULA DE EFICIENCIA ECONÓMICA CON FACTOR DE FRICCIÓN (V2.5)

Para compensar el sesgo cognitivo de planificación en la estimación de plazos:

$$\text{IE} = \frac{\text{Ingreso Esperado (€)} \times \text{Tracción Histórica (0.2 a 1.0)}}{\left( \text{Horas Estimadas} \times \text{Factor de Fricción (1.5x a 2.0x)} \right) \times (1 + \text{Dependencia de Terceros})}$$

* **$1.0\times$ (Cero Fricción):** Activos terminados y maquetados (ej. libros listos para subir a KDP).
* **$1.5\times$ (Fricción Media):** Servicios B2B cerrados (consultoría, masterclasses).
* **$2.0\times$ (Fricción Alta):** Software, videojuegos o proyectos con integraciones complejas.

### 🧪 PROTOCOLO DEL EXPERIMENTO BINARIO DE 48 HORAS

Toda iniciativa aprobada por el tribunal debe definir una **acción falsable de métrica binaria en $\le 48\text{h}$** antes de invertir horas de desarrollo:
* **Ejemplo B2B:** *"Enviar 5 emails con propuesta cerrada. Si en 48h hay $\ge 1$ reunión agendada ➔ GO. Si no hay respuestas ➔ Congelar."*
* **Ejemplo B2C / Audiovisual:** *"Publicar 1 clip/teaser en redes. Si en 48h supera las 500 visualizaciones orgánicas ➔ GO. Si no ➔ Descartar."*

### 🚀 INSTALACIÓN Y USO RÁPIDO

```bash
# 1. Clonar el repositorio
git clone https://github.com/albyojedadev/Arqueologo-Creativo.git
cd Arqueologo-Creativo

# 2. Instalar dependencias para el compilador de Word
pip install python-docx

# 3. Ejecutar el escaneo ligero de metadatos (Fase 1)
python scripts/safe_scanner.py --path "C:/Ruta/A/Tu/Copia_Auditoria" --output "inventario.json"

# 4. Generar el informe oficial maquetado en Word (.docx)
python scripts/generate_docx_report.py --input "informe.md" --output "INFORME_MAESTRO.docx" --author "Tu Nombre"
```
